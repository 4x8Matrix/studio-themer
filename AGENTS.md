# studio-themer

One Zune executable that themes every layer of Roblox Studio (exe patches, Qt theme JSON, on-disk Foundation tokens, built-in plugin bytecode) on Windows and Linux/Wine, with a terminal wizard. A Luau port of `~/Projects/Personal/studio-catppuccin` (Python). Design: `docs/specs/2026-09-19-studio-themer.md`. Plan: `docs/plans/2026-09-19-studio-themer.md`.

## Paradigms

Facts about this codebase. Where a line conflicts with the harness Luau contract (`~/Projects/Personal/Ai-Harness/docs/conventions.md`), this line wins here.

- Runtime is Zune 0.5.6 only; `src/init.luau` refuses any other runtime. `zune.*` is reached directly only for what std_polyfills lacks: `zune.serde.zstd` (`src/rbxm/rbxm.luau`), `zune.fs.embedFile` (`src/assets.luau`), `zune.process.exit` (`src/objects/output.luau`), `zune.luau.compile` (checks). Everything else goes through `luau_packages/std_polyfills`.
- Packages are pesde: `4x8matrix/cli_builder` (commands), `4x8matrix/tui` (wizard), `discord_luau/std_polyfills` (fs, process, io, serde), `discord_luau/logger`. `patches/` holds the one pesde patch (std_polyfills survives a failing `process.cwd` under Wine); `pesde install` applies it.
- Requires: `src/init.luau` uses `@self/...` for its own tree and `./luau_packages/<name>` for packages; every other file uses relative paths (`../../luau_packages/<name>`, `../theme/color`). No aliases in `.luaurc`. darklua bundles it all into `build/studio-themer.luau`; the other runtimes' `@eryx`, `@std`, `@lute`, `@lune` requires inside std_polyfills are excluded in `darklua.json`.
- Kinds and homes: entry -> `src/init.luau` (the only file with top-level calls) · command -> `src/commands/<verb>.luau`, a single cli_builder chain ending in `:build()`; `location.luau` holds the shared `--prefix`/`--exe` options · pure layer -> `src/layers/<layer>.luau` with `apply(...)`, `restore(...)`, `countPristine(...)` · patch -> `src/patches/<name>.luau` with `check(data)` and `apply(data)` on a byte string, offsets 0-based through `binary.luau` · data -> `src/theme/palette.luau`, generated from `palette.py`, types declared above the data they annotate · orchestrator -> `src/pipeline.luau`, never prints, reports through a callback · wizard -> `src/ui/wizard.luau`, same skeleton as create_app's `createWizard` · check -> `checks/<module>.check.luau` under Zune; `checks/support/liveInstall.luau` finds the reference install and prints `skip` when absent.
- Module shape: a table of functions, constants `LOUD_SNAKE` above it, local functions after it, exported types before the return. No classes; the builders come from the packages. Exception: `src/theme/palette.luau` declares its types first because Luau does not resolve a forward-referenced alias inside `table.freeze(x :: T)`.
- Fallible functions return `(value?, errorMessage?)`; commands turn an error into `output.fail`, the one exit path with a non-zero code. `pcall` wraps only third-party or IO calls whose failure is expected (`zstd.decompress`, `readDirEntries`, JSON decode).
- Logger: `src/objects/logger.luau`, `Warn` by default, `--verbose` for `Debug`, sink on stderr. Reports the user asked for go to stdout through `output.line`. A bare `print` is allowed only in checks (`.config.luau`).
- Every colour decision goes through one `mapper.Mapper` from `src/theme/mapper.luau`; Python `round` semantics live in `color.roundHalfEven`. Outputs are byte-identical to the Python tool for the same pristine input, and the differential checks (`exePatches`, `recolor`, `tokens`, `qtTheme`) are the proof; they read the live Vinegar install read-only.
- Backups: `.stock` beside every themed file; the Python suffixes (`.plugverify-bak`, `.orig-bak`, `.catppuccin-bak`) are recognised as pristine and never renamed (`src/studio/backup.luau`).
- Mode: `--mode both|dark|light` selects the Qt slot files and token slot files; plugins always take the theme (both token tables share one bytecode blob).
- Tooling: `scripts/check.sh` (stylua, selene, luau-lsp, checks), `scripts/build.sh` (darklua, `zune bundle` for Linux and, with `scripts/fetch-runtimes.sh`, Windows). House sensors: `~/Projects/Personal/Ai-Harness/binary/check-file` and `run-checks checks zune`. Commits are conventional with a body, no attribution.
- Known package quirk: cli_builder 0.1.0-dev.1 drops the value of `--option=value`; pass options as `--option value`, before the positional argument.
